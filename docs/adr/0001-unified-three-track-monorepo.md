# ADR 0001: Unified Three-Track Pauli Contextuality Monorepo

- **Status:** Accepted (2026-11-24)
- **Context:** Four separate repositories (`hoggar-bound`, `hoggar-bound-lab`, `contextuality-tensor-lab`, `contextuality-evidence-lab`) shared the exact same mathematical domain (multiqubit Pauli / Peres-Mermin contextuality), the exact same Lean 4.35.0 + Mathlib `56a005855ea1` toolchain, and bit-identical copies of `third_party/` (Moonlab WASM, QGTL, quantum_rng). Maintaining four repositories caused root clutter, duplicated Mathlib caches (~8 GB), inconsistent licenses, and fragmented links for external reviewers.
- **Decision:** Consolidate all four Pauli repositories into one canonical repository (`pauli-contextuality-lab`) with one unified `lean/` Lake workspace (exposing `HoggarBound`, `ContextualityTensor`, and `Evidence`), one deduplicated `third_party/`, and three cleanly isolated research tracks under `tracks/` and `papers/`. Keep `kochen-specker-extremal-lab` separate to preserve its zero-Mathlib, 27-second minimal trust base for SAT/DRUP ray-pool minimality proofs. Archive the four superseded GitHub repositories in read-only mode with redirect banners so no existing citations, `0thernes-research-archive` submodules, or Software Heritage SWHIDs break.
- **Consequences:** Single clean entry point for external researchers (including Metod Saniga, Axel Muller, Frédéric Holweck, Colm Kelleher, and Alain Giorgetti), single Mathlib cache, unified CI and Pages portal, and zero broken legacy links.
