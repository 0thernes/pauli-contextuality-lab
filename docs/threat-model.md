# Threat Model

As a formal-verification and computational-mathematics repository, the primary threats are **epistemic and verification-integrity failures** rather than network intrusion.

| Threat Vector | Concrete Risk | Mitigation in This Repo |
|---|---|---|
| **Statement weakening / vacuity** | An AI-assisted Lean proof type-checks a weaker or vacuously true theorem than the paper claims. | Isolated `lean/Challenge.lean` (18 targets) checked against `lean/Solution.lean`; 10 existential `NonVacuity.lean` witnesses + **8 kernel-proved refutations of perturbed headline bounds** (`refute_w52_bound_64` through `refute_pentagram_k2_bound_11`, two also in the 6-kernel comparator); 3 additional closed-fact negative sanity checks in CI; line-by-line `docs/statement-fidelity.md`. |
| **Hidden axioms / `native_decide`** | Soundness bypass via `sorryAx`, custom `axiom` (including `noncomputable`/`scoped`/`local` forms), `@[extern]`, `implemented_by`, or Lean 4.35 `_native.*` compiler-trusted axioms. | Nested-comment-aware zero-forbidden-token CI scan across all 63 non-Challenge `.lean` files; exhaustive `VerifyAll.lean` (`198` explicit `#print axioms` + `2,306` kernel theorem constants) + `VerifyStandalone.lean` + `VerifyPhaseSeven.lean` allowlist strictly limited to `[propext, Classical.choice, Quot.sound]`; verbatim output synced to `README.md`. |
| **Single-kernel soundness bug** | A bug in Lean's official C++ kernel accepts an invalid proof. | `lake comparator --config comparator.json --paranoid` runs independent checkers (`leanchecker-paranoid`, `lean4lean`, `nanoda`, `con-leche`, `con-ron`) alongside `lean-default` in CI on all **18 comparator targets** (other theorems are checked by the standard Lean kernel). |
| **Floating-point illusion** | Floating-point tolerances mask a non-rigorous bound. | Exact integer/rational certificates for every theorem (`C3ExactOptima.lean`, exact Python integer/SymPy scripts); automated `scripts/arithmetic_audit.py` explicitly labels every floating-point script `numerical_approximation`. |
| **C memory unsafety / UB** | Undefined behavior in C11 census/search engines corrupts counts. | All 14 C11 engines compiled with `-std=gnu11 -Wall -Wextra` (zero repo warnings) and executed under `-fsanitize=address,undefined` in CI; every census result cross-checked by independent Python/Lean verifiers. |
| **Citation hallucination or retracted references** | Fabricated, broken, or silently retracted DOI / arXiv / Zenodo reference. | Automated `scripts/check_citations.py` validates BibTeX structure & citation identifiers offline and checks live HTTPS resolution plus Crossref retraction metadata under `--online`. |
| **Supply-chain / secret leakage / artifact tampering / backdating** | Leaked credentials, vulnerable Python packages, silent drift in datasets/vendored WASM/release PDFs, or disputed timestamp provenance. | SHA-256-verified `gitleaks v8.30.1` and `osv-scanner v2.7.1` (report-only) in CI; `data/MANIFEST.sha256` sealed by DigiCert RFC 3161 TSA (`data/MANIFEST.sha256.tsr`, OpenSSL X.509 verified in CI via `scripts/stamp_timestamps.py --verify`) and 3-calendar Bitcoin OpenTimestamps (`data/MANIFEST.sha256.ots`); permanent Software Heritage archival SWHID (`swh:1:snp:bcb2b33b31015225ace11d52fa98b2f93c5b4913`); `third_party/SHA256SUMS.json`, tag-triggered `SHA256SUMS`, and GitHub Sigstore SLSA attestations (`actions/attest-build-provenance@v4`). |
