# Errata, Versioning Policy, and Withdrawal Plan (`ERRATA.md`)

This ledger records substantive mathematical, formalization, bibliographic, and metadata corrections across all releases of `pauli-contextuality-lab` (Defensible Independent AI Research Playbook v1.3, Checklist #39 & H28).

## 1. Versioning and DOI Policy

- **Single version source:** The canonical version lives in `VERSION` (SemVer `MAJOR.MINOR.PATCH`) and is synchronized across `CHANGELOG.md`, `CITATION.cff`, `formalization.yaml`, `lean/lakefile.toml`, `README.md`, and all manuscript headers via automated regression tests (`tests/test_repo_integrity.py`).
- **Preprint revision convention:** Each tagged GitHub release (`vX.Y.Z`) freezes a specific PDF, `lean-axioms-all.log`, `data-MANIFEST.sha256`, `SHA256SUMS`, and source archive. If deposited to Zenodo or HAL, **cite the version-specific DOI** when referencing exact proof line numbers, theorem counts, or artifact hashes, and the **concept/all-versions DOI** only when citing the ongoing repository generically.
- **No fabricated identifiers:** Currently `doi: null`, `arxiv_identifier: null`, and `journal_submission_identifier: null` in `papers/spectral-bounds/unified-metadata.json`. No external DOI or arXiv identifier will be asserted until an actual deposit completes.

## 3. Correction & Withdrawal Plan

If a mathematical error, statement-fidelity mismatch (definition drift or vacuity between a paper claim and its Lean formalization), soundness flaw in a verifier, or undisclosed prior art is discovered:

1. **Report intake:** Open a GitHub issue (tagged `error`, `bug`, or `hole`) or email `0_0@0thernes.art` with the exact commit/version, theorem/file path, and counterexample or discrepancy.
2. **Triage & reproduction (target: within 72 hours):** Reproduce the counterexample or discrepancy, classify it under the 10-class Build Standard v1.2.0 taxonomy, and record an explicit entry in this `ERRATA.md` table and in `CLAIMS.md` / `docs/statement-fidelity.md`.
3. **Correction release (non-fatal errors):** Publish a new SemVer release (`vX.Y.(Z+1)`) fixing the proof, code, and manuscripts, never force-pushing or rewriting tagged history so older citations remain verifiable.
4. **Formal withdrawal (fatal theorem failure):** If a headline theorem fails due to an unrepairable mathematical or definition-fidelity defect:
   - Immediately add a prominent `[WITHDRAWN]` banner at the top of `README.md`, `CLAIMS.md`, the affected manuscript PDF/HTML/TeX, and this `ERRATA.md` explaining the exact failure mechanism and crediting whoever found it.
   - Publish a superseding withdrawal version on GitHub Releases and any external preprint server where the paper has been deposited (e.g., arXiv withdrawal comment, Zenodo new version with withdrawal notice, HAL update, or `ai.viXra.org` replacement notice). Never silently delete prior versions.
